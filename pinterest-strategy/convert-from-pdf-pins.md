# Publishing playbook (quick)

- Spacing: 3–5 pins per tool, spread across 4–7 days. Never dump a tool at once.
- Cross-board reuse: the same conversion can post to 2–3 boards; only change the hook line. (e.g., pdf-to-jpg → Free PDF Tools + Students + Productivity.)
- CTR levers (highest to lowest): before/after visual → concrete number (24 MB, 300 DPI, 40 images) → privacy ("no upload") → free/no-signup. Put at least one in every hook.
- Pair with the Convert to PDF library: pdf-to-jpg ↔ jpg-to-pdf and pdf-to-docx ↔ word-to-pdf make natural "round trip" pin pairs for the Tips board.
- Accuracy guardrail: every privacy claim here is true because conversion is client-side; if a tool ever moves server-side, drop the "never leaves your device" line from its pins.
- Titles ≤ 100 chars; descriptions ≤ 500 chars. On-image hook text stays sentence case.
