## 核心策略要点

### 1. 内容定位
- **目标用户**：学生、职场人士、需要处理 PDF 的普通用户
- **核心价值**：免费、隐私安全、浏览器端处理
- **差异化**：95+ 工具，工作流编辑器，多语言支持

### 2. 内容类型优先级
1. **教程类**（最高优先级）- 展示实际使用价值
2. **清单类** - 易于传播，收藏率高
3. **问题解决类** - 直击痛点，转化率高
4. **对比类** - 建立信任，突出优势
5. **产品展示类** - 展示功能，品牌认知
6. **季节类** - 抓住特定时机，精准流量

### 3. 关键词策略
**主关键词**：
- PDF editor, merge PDF, compress PDF, free PDF tools
- PDF 合并, PDF 压缩, PDF 工具

**长尾关键词**：
- how to merge PDF files, PDF compressor online free
- 如何合并 PDF, 在线 PDF 压缩工具

**场景关键词**：
- student PDF tools, resume PDF format, thesis PDF
- 学生 PDF 工具, 简历 PDF 格式

### 4. 发布节奏
- **Week 1**：创建 15 个核心 Pin，建立账号基础
- **Week 2-4**：每天 3-5 个 Pin，观察数据
- **长期**：每天 3-5 个 Pin，持续优化

### 5. 成功指标
- **月度目标（3 个月后）**：
  - 账号关注者：500+
  - 月展示量：50,000+
  - 网站点击：1,000+
  - 互动率：3%+

## 设计资源

### 品牌色系
- 主色：`#2563eb`（蓝色）
- 辅助色：`#10b981`（绿色）
- 背景：`#f8fafc`（浅灰）
- 文字：`#1e293b`（深灰）

### Logo
- 路径：`/public/images/logo.png`
- Pinterest 头像尺寸：165 x 165 px

### 图片规格
- Pin 尺寸：1000 x 1500 px（2:3 比例）
- 格式：PNG 或 JPG
- 最大文件大小：32MB

## 注意事项

1. **不要购买粉丝或虚假互动**
   - 影响账号信誉
   - Pinterest 会惩罚

2. **保持内容质量**
   - 不要发布低质量 Pin
   - 图片要清晰、专业

3. **遵守 Pinterest 规则**
   - 不要 spam
   - 不要发布违规内容
   - 尊重版权

4. **持续性和耐心**
   - Pinterest 是长期策略
   - 效果通常 2-3 个月显现
   - 不要过早放弃
