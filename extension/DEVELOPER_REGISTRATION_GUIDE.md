# Chrome Web Store 开发者账号注册指南

## 📋 注册前准备

### 你需要:
- ✅ **Google 账号** (Gmail 或 Google Workspace 账号)
- ✅ **信用卡或借记卡** (支付 $5 注册费)
- ✅ **有效邮箱** (接收通知和审核结果)
- ⏱️ **10-15 分钟** 完成注册

### 注册费用:
- **一次性费用**: $5 USD
- **支付方式**: Visa, MasterCard, American Express
- **费用用途**: 防止垃圾和恶意扩展
- **终身有效**: 一次支付,终身发布

---

## 🚀 注册步骤详解

### Step 1: 访问开发者控制台

1. 打开浏览器,访问:
   ```
   https://chrome.google.com/webstore/devconsole
   ```

2. 或者 Google 搜索: "Chrome Web Store Developer Dashboard"

### Step 2: 登录 Google 账号

1. 如果未登录,会要求你登录 Google 账号
2. 使用你的 Gmail 或 Google Workspace 账号登录
3. **建议**: 使用公司或项目专用账号,方便团队管理

### Step 3: 接受条款

1. 阅读 **Chrome Web Store 开发者协议**
2. 阅读 **Chrome Web Store 项目政策**
3. 勾选 "我已阅读并同意..."
4. 点击 **"同意"** 或 **"Continue"**

### Step 4: 支付注册费

#### 填写支付信息:

```
开发者名称: PDFkoi Team (或你的公司/个人名称)
开发者邮箱: your-email@example.com
```

#### 支付 $5 注册费:

1. 点击 **"支付注册费"** (Pay registration fee)
2. 选择支付方式:
   - 💳 信用卡
   - 💳 借记卡
   - 💳 Google Pay (如果已设置)

3. 填写卡片信息:
   ```
   卡号: **** **** **** ****
   到期日: MM/YY
   CVV: ***
   账单地址: (你的地址)
   ```

4. 点击 **"支付"** (Pay)

#### 支付注意事项:

⚠️ **常见问题**:
- **币种**: 以美元 (USD) 结算
- **汇率**: 银行会自动转换为本地货币
- **手续费**: 可能有国际交易手续费 (约 1-3%)
- **账单名称**: 会显示为 "Google Commerce Ltd" 或类似

💡 **提示**:
- 使用 Visa 或 MasterCard 成功率最高
- 确保卡片支持国际支付
- 确保卡内余额充足 (建议至少 $10)

### Step 5: 验证身份 (可能需要)

某些情况下,Google 可能要求额外验证:

1. **邮箱验证**: 检查邮箱中的验证链接
2. **手机验证**: 接收短信验证码
3. **身份文件**: 极少数情况需要

### Step 6: 完成注册

✅ 支付成功后:
- 你会看到 **"开发者控制台"** 主页
- 可以开始上传扩展了
- 会收到确认邮件

## 💳 支付问题排查

### 如果支付失败:

#### 常见原因:

1. **卡片未开通国际支付**
   - 解决: 联系银行开通国际支付功能
   - 或者使用另一张卡

2. **余额不足**
   - 确保卡内至少有 $10 (包含可能的手续费)

3. **卡片信息错误**
   - 仔细检查卡号、有效期、CVV
   - 确认账单地址正确

4. **银行拒绝交易**
   - 有些银行会拒绝小额国际交易
   - 联系银行说明是 Google 开发者注册费

#### 替代支付方式:

如果信用卡不行,可以尝试:
- **虚拟信用卡**: 如 Revolut, Wise
- **PayPal 关联卡**: 通过 Google Pay 绑定 PayPal
- **朋友帮忙**: 请已注册的开发者添加你为团队成员

### 如果你是公司:

   - 更专业
   - 方便团队协作
   - 可以转移所有权

2. **填写公司信息**:
   ```

   开发者网站: https://yourcompany.com
   联系邮箱: developer@yourcompany.com
   ```

3. **准备公司材料** (可能需要):
   - 营业执照
   - 公司网站
   - 官方邮箱

## 👥 团队协作

注册后可以添加团队成员:

### 添加成员步骤:

1. 进入 **"设置"** → **"组织"**
2. 点击 **"添加成员"**
3. 输入成员的 Google 账号邮箱
4. 设置权限级别:
   - **所有者** (Owner): 完全控制
   - **管理员** (Admin): 可以发布和管理
   - **开发者** (Developer): 只能查看

## ⚠️ 注意事项

### 账号安全:

1. **启用两步验证** (2FA)
   - 保护账号不被盗
   - Google Authenticator 或短信验证

2. **定期检查活动**
   - 查看登录记录
   - 发现异常立即更改密码

3. **备份恢复码**
   - 保存 Google 账号恢复码
   - 防止无法登录

### 政策合规:

⚠️ **违规会导致账号被封**:
- 不要发布恶意软件
- 不要误导用户
- 不要侵犯版权
- 遵守隐私政策

📖 **仔细阅读**:
- Chrome Web Store 项目政策
- 开发者计划政策
- 用户数据政策

## 💡 常见问题 (FAQ)

### Q: $5 注册费可以退款吗?
**A**: 不可以。这是一次性不可退费用。

### Q: 一个账号可以发布多少个扩展?
**A**: 无限制。$5 是账号注册费,不是每个扩展的费用。

### Q: 注册多久后可以发布?
**A**: 支付成功后立即可以上传扩展。

### Q: 可以转移扩展到其他账号吗?
**A**: 可以,但需要双方都是注册开发者。

### Q: 中国开发者可以注册吗?
**A**: 可以!全球任何地区都可以注册。

### Q: 需要营业执照吗?
**A**: 个人开发者不需要。企业建议提供。

### Q: 支付失败怎么办?
**A**: 尝试其他卡,或联系 Google 支持。
